## What it does

- **One key.** caps lock starts and stops the recording. The lamp on the key stays lit while you record, so you can see it running.
- **System audio without a virtual driver.** BlackHole and similar audio devices are not required — caps REC captures what your Mac is playing through macOS itself.
- **Microphone with channel selection.** Pick the device *and* the input channel, so multi-channel audio interfaces work properly. Includes latency compensation.
- **Separate stems, optionally.** One switch writes system audio and microphone as separate 48 kHz WAV files alongside the video, ready for a DAW.

## Requirements

- macOS 15 or later
- Apple silicon or Intel
- Signed and notarized

## Privacy

Recordings are written to the folder you choose and are never uploaded. The network is used once, to check your licence key when you activate. caps REC reads whether the caps lock lamp is lit — it never requests input monitoring.
